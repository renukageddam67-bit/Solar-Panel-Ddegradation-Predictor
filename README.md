# Solar Panel Degradation Predictor

A simple web-based application that predicts the estimated capacity of a solar panel after a specified number of years based on its initial capacity and annual degradation rate.

## Features

- Enter the initial solar panel capacity in watts.
- Enter the annual degradation rate as a percentage.
- Enter the number of years.
- Calculate the estimated capacity after the specified period.
- Display the prediction instantly on the webpage.
- Simple and user-friendly interface.

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

The application calculates the estimated solar panel capacity using the initial capacity, annual degradation rate, and number of years.

**Formula:**

Estimated Capacity = Initial Capacity × (1 − Degradation Rate / 100) ^ Years

## How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Enter the initial capacity, degradation rate, and number of years.
4. Click the **Predict** button.
5. The estimated capacity will be displayed.
